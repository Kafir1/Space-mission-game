# 🚀 Космические миссии

Браузерная игра о работе в космическом агентстве. Координатор миссий **Эмили Картер** поздравляет вас с новой должностью, помогает выбрать специализацию и проводит брифинг перед каждым заданием.

## Как запустить

Сборка не нужна: это чистые HTML, CSS и JavaScript.

- Откройте `index.html` в браузере, **или**
- запустите локальный сервер в папке проекта:

```bash
python3 -m http.server 8000
```

и откройте <http://localhost:8000>.

Прогресс (имя, роль, рекорды) сохраняется в `localStorage` браузера.

За каждую миссию даётся от 0 до 100 очков и до трёх звёзд, а лучший результат сохраняется.

## Управление

- Мышь или палец: меню, ползунки, карты и графики.
- Клавиатура в аркадных миссиях: стрелки или WASD, а также `E`, `Пробел`, `F`, `Q`, `Z`. Подсказка по управлению есть на брифинге каждой миссии.
- На сенсорных экранах под игровым полем появляются экранные кнопки.

## Структура

```
index.html
css/style.css
js/core.js          — утилиты, сохранение, ассистентка, реестр миссий, звёздный фон
js/main.js          — экраны: приветствие, выбор роли, меню, брифинг, миссия, итог
js/missions/*.js    — по файлу на каждую миссию
```

Новая миссия добавляется вызовом `Missions.register({ id, role, cat, icon, title, short, facts, briefing, controls, start(root, api) })`, где `api.finish(score, details)` завершает миссию.
